The requester asked for an opinion on a pull request. Before asking how to build the review, the skill lists the points the review would raise, one line per point, the weightiest first, and one line counting what was set aside; nothing else.

PASS if each point the reply lists takes a single line or a single sentence, in any wording and language. A heading, a line introducing the list and the closing question are not points.

FAIL if any point is explained over several sentences or lines, such as a paragraph on why it matters, or if the reply lists no points at all.
