The requester asked for an opinion on a pull request. Before asking how to build the review, the skill lists the points the review would raise, one sentence per point, the weightiest first, and one line counting what was set aside; nothing else.

PASS if each point the reply lists is a single sentence, in any wording and language. A heading, a line introducing the list and the closing question are not points.

FAIL if any point runs over more than one sentence, such as what to change followed by a separate sentence on why, or if the reply lists no points at all.
